This challenge will get you started using github and github teams, git branches and tables in markdown.

Instructions
Modify markdown file profiles.md to create a personal profile which will introduce you to your project team. This should profile the relevant skills you currently have for the course project, and what relevant skills you are interested in leaning for the course project.

Obtain a github account you will use for this course. You can use an existing account if you like.

Provide the instructor with your github id by completing the only item in the quiz on brightspace. The intructor can then complete your team assignment and issue an invitation on github to your team repository.

After you obtain access to the team repository, clone a local repo on your own workstation/laptop. Create your own git branch to complete your assignment elements on your local repo. The branch name should be {munname}-asgn1 based on your mun login name.

Place your profile on your branch in the file doc/profiles.md.

Submit by pushing your branch up to your team remote github repo before the due date expires. Do not isuue a pull request.

You can check the remote from the github dashboard to make sure your branch is there if you are not sure.

For individual grading, we need to know which branches and activities belong to you. Make sure the author of the commits on your branch is logged as you - the author entry should inclue your mun login name. You can check the git log locally or on the github dashboard to confirm this information is entered correctly.
